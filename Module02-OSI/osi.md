# OSI Model

## Purpose

The OSI model helps understand how devices communicate across a network.

## 7 Layers

7. Application
6. Presentation
5. Session
4. Transport
3. Network
2. Data Link
1. Physical

## What I learned

- Each layer has a specific role.
- Data is encapsulated when sent.
- Data is decapsulated when received.
- Routers work mainly at Layer 3.
- Switches work mainly at Layer 2.
