# Switch Interfaces Lab

## Objective

Practice configuring and verifying switch interface settings in Cisco IOS.

## Tasks Completed

- Configured interface speed.
- Configured duplex mode.
- Enabled and disabled interfaces using `shutdown` and `no shutdown`.
- Verified interface status.
- Observed auto-negotiation behavior.
- Checked interface statistics using `show interfaces`.
- Identified interface errors and counters.

## Commands Used

```bash
show interfaces
show interfaces status
interface FastEthernet0/1
speed 100
duplex full
shutdown
no shutdown
```

## Skills Practiced

- Switch Interface Configuration
- Speed and Duplex Configuration
- Auto-Negotiation
- Interface Status Verification
- Cisco IOS CLI
- Basic Network Troubleshooting

## Result

Successfully configured switch interfaces, verified interface status, and analyzed interface statistics using Cisco IOS commands.
