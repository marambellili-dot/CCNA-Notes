# IPv4 Addressing Lab

## Objective

Practice IPv4 addressing by configuring IP addresses and verifying network connectivity.

## Tasks Completed

- Configured IPv4 addresses on network devices.
- Configured subnet masks.
- Assigned default gateways.
- Verified connectivity using the `ping` command.
- Identified network and host portions of IPv4 addresses.
- Confirmed successful communication between devices.

## Skills Practiced

- IPv4 Addressing
- Subnet Mask Configuration
- Default Gateway Configuration
- Network Verification
- Cisco Packet Tracer

## Result

All devices were successfully configured and communication between hosts was verified.
