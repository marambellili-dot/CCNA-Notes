# Ethernet

## What is Ethernet?

Ethernet is the most widely used LAN technology.

## Main Characteristics

- Works mainly at Layer 2.
- Uses MAC addresses.
- Transfers data using frames.

## MAC Address

A MAC address uniquely identifies a network interface.

Example:

00:1A:2B:3C:4D:5E

## Ethernet Frame

Contains:

- Destination MAC
- Source MAC
- Type
- Data
- FCS

## Role of a Switch

A switch learns MAC addresses and forwards frames to the correct device.

## What I Learned

- Ethernet uses frames.
- Switches work with MAC addresses.
- MAC addresses are used inside the local network.
- FCS helps detect transmission errors.
